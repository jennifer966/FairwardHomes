# Prototypes

Clickable design prototypes made as Claude Design canvases. They are **design artifacts with sample data**, not production code.

| Folder | Canvas (private link) | Contents |
| --- | --- | --- |
| `seller-app/` | https://claude.ai/artifact/EazbDJ7XsMJtFCWr1A5i1f | 8 phone screens (doc 05) |
| `broker-console/` | https://claude.ai/artifact/GB8dnifw1TeGYUXvjBKAib | 9 broker screens + 6 agent screens (docs 06, 07) |

Each `*.dc.html` file is one screen, and `canvas.json` lays the screens out. The files depend on the canvas runtime (`support.js`), so they render inside the canvas rather than as standalone web pages. Open the canvas link and press **Play** on the first screen.

To revise a screen, ask Claude to edit the canvas, or edit the file here and republish it to the same canvas.
